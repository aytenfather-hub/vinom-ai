## الموقع (Flutter Web)
الرئيسية `/`، المنيو `/menu`، القسم `/menu/:id`، المنتج `/product/:id`، الفروع `/branches`، الفرع `/branches/:id`، العروض `/offers`، الطلب `/cart` ← `/checkout`، الحساب `/account`، التتبع `/track/:id`، الدعم `/support`، السياسات `/policies/:slug`.
كل صفحة عامة لها نسخة HTML مولّدة مسبقاً لمحركات البحث.

## شاشات المحلات
قوالب أفقية (16:9، 1920×1080 وما فوق): «منيو القسم»، «منتج مميز»، «عرض»، و«قائمة تشغيل» تدور بينها.
البيانات لكل فرع وبحسب اللغة. **لا يُعرض سعر غير معتمد أو عرض خارج فترته.** أي عنصر ناقص يُخفى ولا يُعرض فارغاً.

## المسارات الرئيسية
**العميل (الطلب الأول):** البداية ← اللغة ← الفرع ← الخدمة ← الرئيسية ← قسم ← المنتج (حجم + إضافات + ملاحظة) ← أضف للسلة ← السلة ← العنوان / الاستلام ← القسائم ← المراجعة ← الدفع ← التأكيد ← التتبع.

**العميل (إعادة الطلب):** الطلبات ← طلب سابق ← «اطلب مجدداً» ← فحص التوفر والسعر الحالي ← السلة (مع تنبيه بأي تغيّر).

**موظف الطلبات:** طلب جديد (تنبيه) ← قبول ← تحضير ← جاهز / سُلّم للمندوب ← مكتمل. الرفض أو الإلغاء يتطلب سبباً ويُسجَّل.

**مدير الفرع:** يفتح الفرع ← يضبط أوقات العمل ← يوقف صنفاً نفد ← يتابع طلبات فرعه ← يراجع تقرير اليوم.

**المالك:** يعتمد بيانات فرع ← يعتمد الأسعار لكل فرع ← يعتمد عرضاً ويجدوله ← يعيّن المستخدمين والصلاحيات ← يراجع سجل التعديلات.

**مسؤول المحتوى:** يضيف صور المنتجات الأصلية وأوصافها ← يرسل للاعتماد ← يجدول محتوى الشاشات.
